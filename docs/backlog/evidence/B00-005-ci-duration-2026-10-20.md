# B00-005 / B00-011 CI duration improvement — 20 October 2026

Scope: narrow `scripts/verify-clean-rebuild.mjs` and update B00-005 documentation following the CI review. The full application verification command, workflow, security gates, and current-head merge requirement remain unchanged.

## Baseline and change

[Successful run 39335583741](https://github.com/dynamicet/hallelujah-website/actions/runs/39335583741) took 19m18s: ordinary verification took 9m13s and clean reconstruction took 9m14s. Dependency installation took 13s and asset tooling setup took 22s. Reconstruction previously repeated the entire verification suite.

Clean reconstruction still excludes dependency/build output, installs the frozen graph, checks lockfile equality, and compares linked workspace importer graphs. It now executes `build`, `content-build:check`, `accessibility:smoke`, `budgets:smoke`, and `runtime:smoke` sequentially against the independent build. A failed command still stops reconstruction and its temporary directory is cleaned up. This proves dependency graph equality and a working independent production build, not bit-for-bit compiled artifact equality.

The preceding `pnpm verify` retains all source checks and browser matrices, including enlarged-text and fallback-font regressions. Standalone `pnpm rebuild:verify` complements that suite; it does not replace it. No test cases, workflow gates, or security checks were removed. Parallel jobs and caching are outside this change.
