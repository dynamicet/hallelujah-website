# Controlled Versioned Utility Statements

B02-009 extends the governed-record JSON boundary with `utility-statement` records.
Each immutable series/type/version/predecessor identifies a retained document version.
Every version uses a distinct public ID and localized canonical slug; production historical
routing and retention policy remain separate decisions.

Content, privacy/legal or accessibility reviews and independent general approval are required.
Contact bindings refer to a canonical settings fact and carry purpose-specific operations evidence;
they never copy contact values into policy records. Service dependencies resolve to canonical
service records. Approval/publication rejects missing, stale or revoked dependencies.
Statement references are retained when dependencies retire, preserving historical provenance and
allowing a current notice to display unavailable contacts truthfully. Consumption/collection checks
deny retired dependencies; expired policies disappear.

The complete inventory covers appointment, search and accessibility-support flows. Each flow is
disabled or planned with explicit purpose, categories, recipients, access, transport, retention,
deletion and choices. Optional providers are absent. Contract evaluation compares the current
approved public version ID and entire canonical inventory, rather than trusting a revision label.
It requires a current contact and service dependencies. The result always has `enabled: false`.
It is a testable prerequisite contract, not a collection enablement control or legal approval.

Accessibility specimens state tested date/scope, methods, evidence and known limitations with
a limited-testing-only claim. They provide no legal or full-conformance certification.
Authenticated local reads serialize with CMS writes and recheck persisted approval roles.
Default/public consumption is denied even if the synthetic flag is removed.

Semantic internal specimens escape text, display owner/version/effective/review dates, use native
fragment navigation and provide full processing/testing details without scripts, forms or external links.
Amharic specimens are explicitly unreviewed shaping fixtures. No public/CMS route is introduced.
