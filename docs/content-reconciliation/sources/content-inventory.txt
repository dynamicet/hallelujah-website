## Suggested website content model

| Template | Primary source |
| --- | --- |
| Home | `hospital-profile.json` plus selected approved doctors/services |
| About | Story, mission, vision, values, leadership, verified facts |
| Doctor directory | `data/doctors.json`, filtered to approved current records |
| Doctor profile | One doctor record plus hospital-supplied biography/credentials/languages |
| Service directory | `data/services.json`, grouped by `group` |
| Service detail | One service record plus hours, location, preparation, owner, and CTA |
| Emergency | `hospital-profile.json.emergency_and_ambulance` plus approved safety guidance |
| Appointment | `hospital-profile.json.appointment_request` plus privacy, consent, and response expectations |
| Contact / directions | `hospital-profile.json.contact` plus verified wayfinding and hours |
| Patient & visitor guide | Visitor journey plus missing admission, visit, payment, accessibility, and discharge content |
| Careers | Current vacancy page plus hospital-owned recruitment policy/content |
| Legal and privacy | New hospital/legal content required; no usable source copy found |
